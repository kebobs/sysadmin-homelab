# Ubuntu Server Installation

## Project Overview

This project is part of my personal system administration home lab.

The goal is to install Ubuntu Server in a virtual machine and learn the fundamentals of Linux server administration.

## Environment

- Operating System: Ubuntu Server
- RAM: 4 GB
- CPU: 2 cores 
- Storage: 10 GB
